# claude-skills

Personal Claude Code skills for daily workflows.

Built and maintained by [Shivam Tiwari](https://linkedin.com/in/shivamtiwariin) — Head of Product & Growth at The Good Bug, ex-founder (Apli.ai), building Claw-work.

---

## Skills

| Skill | Trigger | What it does |
|-------|---------|--------------|
| [setup](./setup/SKILL.md) | `/setup` | First-time onboarding wizard |
| [draft-linkedin-post](./draft-linkedin-post/SKILL.md) | `/draft-linkedin-post` | Draft a LinkedIn post from a topic or angle |
| [sprint-summary](./sprint-summary/SKILL.md) | `/sprint-summary` | Pull GitHub board and summarize sprint status |
| [cold-email-founder](./cold-email-founder/SKILL.md) | `/email-founder find\|add\|update\|share` | Research AI/tech/e-commerce founders, find their email, draft and send a cold email |

---

## How to use

Drop any skill folder into `.claude/skills/` in your project. Claude Code picks them up automatically.

Each skill has a `SKILL.md` with trigger conditions and step-by-step instructions.
